近况

2026年06月10日 23:13

今天是 2026 年 6 月 10 号，稍微记录下最近的状况，就不用什么洋文了。

从上次记录开始，按照时间顺序讲讲。

电子设计大赛

校赛寄了。测试前一天失去了所有心气，甚至最后都没到比赛场地。到现在总结起来，痛点就那么几个：

  1. 代码调试后硬件是否按预定程序运行，纯看运气，需要反复按 restart 才偶尔能成功一次（CCS 是真难用）。在此基础上，复位之后几乎不会再自动运行烧录的程序，莫名其妙的——只有一次成功了，脱离电脑后按复位，轮子转了起来。
  2. 甚至搞不来一个打孔机，老徐”超级拼装”的灰度模块一点也不靠谱。
  3. 最后陀螺仪没能安上小车，想买块小面包板，但没时间了。
  4. 如果只是自己的话，放弃时没有任何责任和愧疚感。

到现在，第一条我都没搞清楚是为什么——真不甘心，有空了一定得当面请教懂行的人。

校赛失败后有点沉沦，觉得自己是个废物，觉得以前只是沉浸在自己的小世界里，一出来直接现原形了。
队友也挺坑的，尤其是 sz，拉我打比赛说要他自己保研加分，结果 0 参与；发微信居然在图书馆学习……
在实验楼占的位置还被人霸占了，去的时候那人居然在打王者荣耀。算了，不多说了。

后来在寝室猛打游戏，把《古墓丽影：暗影》通关了。现在想起来好像也一般，但可能是压抑太久，玩得很开心。

慢慢安慰自己：自己原来一直是个封闭的系统，不断熵增，现在多少和外界打通了。而且比赛过程中确实成长很快——之前写的设置中断，现在来看进度推进简直慢的可怜，还沾沾自喜。

数模校赛

马上报复性地报了数模校赛，现在还没正式开始。阴差阳错居然是编程手，取了个名字叫 “金化统”，三个学院名拼的，挺满意。

找队友的时候有个小插曲——在校园频道看到一位数统院的同学：意义不明的英文网名，可爱的动漫头像，还有性别女……加上好友一开始居然没怀疑那个过于男性化的名字。后来打开 QQ 空间的旅行照：粗糙的小胖手，还有宾馆里他的裤衩同学……

电梯里

某天在电梯里看到一个穿绿衣服的女生，很瘦，戴着白色有线耳机。到了顶层居然呆呆地不出来（还是最靠近门的位置），最后仓促跑出去，往五楼左侧靠图书馆方向跑了。

回去的路上，愈发有种说不清的感觉。回去边看比赛边吃外卖（又开始吃减脂餐了，其实还挺好吃）。比赛结束立马狂蹬自行车骑到教学楼，4 分钟就骑到了，最后没在具体教室找到——不过好歹是见到了，第一眼是从窗户的倒影上看到的，似乎也没有那么漂亮，但还是很酷。

之后挨个教室看，打卡机居然没有班级。原本以为是文科课程，结果整个5楼不是自动化就是计算机。折腾了好久，在信息门户课表上一个个试，居然真翻到了 B514 周二三四节课的班级：自动化 2301——不过现在还不确定就是了。

之后莫名其妙想用 Claude Code 编个查课表的脚本，各种类别查询都要有。下午没搞出来（考了社会主义发展史，真有作弊的），晚上好歹写出来了。查资料时看到一个学长留下来的痕迹，挺有意思，考虑要不要加微信。

腾讯实训营

今天下午去了腾讯的实训营，回想有价值的几个点：

  1. 项目启动前：可以给 agent 喂你以前的工作资料，让它知道你是干嘛的
  2. Memory Skill：可以在对话中不断积累形成
  3. 个人数据库：好像很重要，得整一个
  4. AI 筛简历：居然已经在用了，得想个办法应对

有个黑客松比赛，看看能不能参加。
